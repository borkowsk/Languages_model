"Sequential bias" syntax
========================

[aM [& bN [& cP]]?] dR : [-] S 

a,b,c — designation of conditional layers.
A letter from the set: "a b c A B C f s t F S T."
Any order, but there can be no repetitions in a single definition.
M,N,P — designation of the states searched for in the conditional layers. Integers from 1 to the "number of states".

d — designation of the target layer. It must be present.
R — designation of the state in the target layer. It must be present. An integer from 1 to the "number of states".

? — ? à la C language — ends the condition in the bias instruction.
: — precedes the bias value.
S — bias value. An integer. It should be reasonably proportional to the maximum strength.
[...] - means that ... is an optional element.

Translation into a natural(-ish) language:
If for an agent
the value of meme 'a' equals "M" and the value of meme 'b' equals "N" and the value of meme 'c' equals "P"
then
for value "R" of meme 'd', increase the counter by "S" 


EXAMPLES:
---------

for CLSS=4 

BIAS="a1:25" - unconditional bias itself (simulation performed via SIMPLE_BIAS procedure)
BIAS="a1?b1:25" - a typical sequential bias. If "a1" is already present, adopting "b1" has a bias = 25
BIAS="a1:25 a1?b1:25" - an example of a sequential bias preceded by an unconditional one
BIAS="a4:10 a4?b4:10 a4&b4?c4:20" - an unconditional bias supporting a sequence of sequential biases

BIAS="b4?a4:10 c4?a4:10" - two sequential biases from other layers support the state in the first layer
BIAS="b4?a4:10 c4?a4:10 a4?b4:5 a4?c4:5" - the same, but with reciprocation
BIAS="a4:10 b4?a4:10 c4?a4:10" - an unconditional bias supported by sequential ones from other layers — can sometimes reach 30

BIAS="a1?a1:-10" - a suicidal trait
BIAS="a1?a4:10" - an altruistic suicidal trait

BIAS="a4?a4:50" - a ratchet bias. If "a1" is already present, the decision to remain has a bias = 50
BIAS="a4?a4:50 a4&b4?b4:50 a4&b4&c4?c4:50" - ratchet biases combined into a sequence

BIAS="a4?b4:50 b4?a4:-50" - a short suicidal loop
BIAS="a4?b4:50 b4?c4:50 c4?a4:-50" — a long suicidal loop
BIAS="a4?b4:50 b4?a4:-50 b4?c4:50 c4?b4:-50 c4?a4:50 a4?c4:-50" - "mutually unfair retaliatory reactions" — overall positive, especially if the value is increased to 150

BIAS="a4?b4:-150 b4?a4:-150" - simple exclusion. Other states win
BIAS="a4?b4:50 b4?a4:50 b4?c4:-50 c4?b4:-50 c4?a4:50 a4?c4:50" — "triangle conflict"
BIAS="a4?b4:150 b4?a4:150 b4?c4:-150 c4?b4:-150 c4?a4:150 a4?c4:150" — "drastic triangle conflict"
BIAS="a4?b4:50 b4?a4:50 b4?c4:-100 c4?b4:-100 c4?a4:50 a4?c4:50" — energetically symmetrical "triangle conflict" — indirect exclusion where other states lose
