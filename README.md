# Languages_model
A model for the evolution of humanity's number of languages ​​used in projects with Peter Culicover

## USAGE
```
language -gray+ AUTO=5 WIDTHWIN=150 HEIGHTWIN=51 MAX=10 LOGC=10 LOGF=log2.out
```
Most useful options:

* -gray+  - wyswietla w szarosciach
* AUTO=5  - 5 powtorzen eksperymentu (bez czekania na usera)
* WIDTHWIN=150 HEIGHTWIN=51 - rozmiary okna; male dla maksymalnego przyspieszenia
* MAX=10  - 10 krokow kazdej symulacji
* LOG=10  - zapis co 10 krokow, czyli na koncu. Zostanie zapisany stan 0 i koncowy.
* LOGF=log2.out - nazwa pliku outputu.
* HELP - list of all possible options.
