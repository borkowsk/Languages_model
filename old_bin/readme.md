#What are these files?

This directory contains various old binary versions of the program to run 
under Windows.

Since these are builds from the 2000s, old __Windows__ versions or specific and/or 
specific startup configurations are required.

You may be able to run them under __Linux__ using _wine_, but you need one of 
these files: 

`CC3260.DLL`, `CC3270.DLL` or `CC32100.DLL`

Files `LanguagesSW2.04a.exe` and `LanguagesSW2.1x.exe` were recompiled in 2011 
and 2013 for classes with students and have a greater chance of working correctly.
